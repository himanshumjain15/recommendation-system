# Hybrid Movie Recommendation System

A hybrid recommendation system (collaborative filtering + content-based) with an offline
A/B testing layer comparing it against a popularity baseline, built on the MovieLens
dataset.

## Setup

1. Clone the repo and create a virtual environment:
   ```powershell
   python -m venv .venv
   .venv\Scripts\Activate.ps1
   pip install pandas numpy matplotlib ipykernel jupyter_client jupyter_core
   ```

2. Download the dataset (not committed to the repo — downloaded fresh):
   ```powershell
   Invoke-WebRequest -Uri "https://files.grouplens.org/datasets/movielens/ml-latest-small.zip" -OutFile "sample_data\inputs\ml-latest-small.zip"
   Expand-Archive -Path "sample_data\inputs\ml-latest-small.zip" -DestinationPath "sample_data\inputs" -Force
   Remove-Item "sample_data\inputs\ml-latest-small.zip"
   ```

3. Open the `notebooks/` folder in VS Code and select the `.venv` kernel to run the analysis.

## Project structure

```
sample_data/
├── inputs/     # raw MovieLens files (gitignored, downloaded via step 2 above)
└── outputs/    # processed/derived data (gitignored, generated by notebooks/scripts)
parser/         # data loading and cleaning code
scoring/        # recommendation logic (collaborative filtering + content-based + hybrid)
tests/          # test suite
docs/           # notes and write-ups
notebooks/      # exploratory analysis and model development
```
